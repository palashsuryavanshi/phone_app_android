# Phone App — Android

A premium Android Phone application built with Kotlin and Jetpack Compose.

## Features

- 📱 Full dialer with contact matching
- 💬 Call history and recents
- 👤 Contact management with CRUD
- ⭐ Favorites with quick access
- 🎨 Deep personalization (themes, colors, shapes, wallpapers)
- 🔒 Privacy-first design with local data storage
- 🛡️ Spam protection with number blocking
- 📞 Real calling integration via Android Telecom framework
- ♿ Accessibility support (large touch targets, font scaling, reduced motion)
- 🌙 Dark/light/AMOLED themes with dynamic color

## Build

```bash
./gradlew assembleDebug
```

## Install

```bash
./gradlew installDebug
```
