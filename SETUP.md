## Setup Options

### Option 1: Manual Installation (Recommended for Full Development)

Install the required tools manually:

#### 1. Install JDK 17

Download from [Adoptium](https://adoptium.net/) or use:

**Windows (winget):**
```powershell
winget install EclipseAdoptium.Temurin.17.JDK
```

**macOS (brew):**
```bash
brew install --cask temurin@17
```

**Linux (apt):**
```bash
sudo apt install openjdk-17-jdk
```

#### 2. Install Android CLI Tools

Download from [Android Developer Site](https://developer.android.com/studio#command-tools):

1. Download command-line tools for your platform
2. Extract to `C:\Users\oggyt\AppData\Local\Android\Sdk\cmdline-tools\latest`
3. Run:

```bash
export ANDROID_HOME="C:\Users\oggyt\AppData\Local\Android\Sdk"
export JAVA_HOME="C:\Program Files\Eclipse Adoptium\jdk-17..."

# Install required components
sdkmanager "platform-tools" "platforms;android-34" "build-tools;34.0.0" "emulator"
```

#### 3. Gradle Wrapper (Generated by Project)

The project's Gradle wrapper will be created automatically. No manual Gradle installation needed.

#### 4. Environment Variables

Add to your shell profile (`~/.bashrc`, `~/.zshrc`, or Windows Environment Variables):

```bash
export JAVA_HOME="path/to/jdk-17"
export ANDROID_HOME="C:\Users\oggyt\AppData\Local\Android\Sdk"
export PATH="$ANDROID_HOME/platform-tools:$ANDROID_HOME/cmdline-tools/latest/bin:$PATH"
```

## Troubleshooting

### JDK Not Found
Ensure `JAVA_HOME` points to JDK 17, not JRE. Check with:
```bash
echo $JAVA_HOME
"$JAVA_HOME/bin/java" -version
```

### SDK Manager Not Found
Ensure `ANDROID_HOME` is set and `cmdline-tools` is installed at:
```
$ANDROID_HOME/cmdline-tools/latest/bin/sdkmanager
```

### Build Fails with SDK Version Errors
Ensure you have the correct platform and build-tools installed:
```bash
sdkmanager "platforms;android-34" "build-tools;34.0.0"
```

### Namespace/AGP Version Issues
The project uses Android Gradle Plugin 8.2+ which requires:
- Gradle 8.2+
- Kotlin 1.9+
- Java 17
